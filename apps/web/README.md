# TrustLayer web

Phase 3A interface foundation. This is a local development preview with fictional, explicitly labeled data. There is no wallet connection, RPC client, transaction submission, backend, or evidence storage.

From the repository root, install with `npm.cmd --prefix apps/web ci`, then run `npm.cmd run web:dev`. Open http://127.0.0.1:3000. Refreshing resets draft forms, sample/empty mode and preferences. No blockchain node is needed.

See [Phase 3A](../../docs/PHASE3A.md) for routes, components, commands, verification and Phase 3B prerequisites. Do not copy contract ABIs or load the checked-in ephemeral manifest as a live deployment.
